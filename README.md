# wannit · Landing

Landing estática basada en los diseños aportados, con la identidad actual de wannit.

HTML, CSS y JavaScript sin dependencias de ejecución ni compilación. Las fuentes y sus licencias están en `assets/fonts/`. Ilustraciones SVG originales creadas para la demo. Datos de la demo ficticios, separados de la colección real. No se incluyen datos personales de la wishlist.

## Desarrollo

Servir la carpeta con un servidor HTTP estático.

## Publicación

GitHub Pages desde la raíz de la rama `main`. URL: https://martinzg16.github.io/wannit/

La descarga incluye la extensión v0.7.5 para instalación manual en Chrome. No está publicada en Chrome Web Store.
